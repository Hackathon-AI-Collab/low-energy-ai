# Search and Rescue Procedures

## Collapsed Structure Assessment

### Initial Assessment
1. Ensure scene safety
2. Establish incident command
3. Conduct size-up of structure
4. Identify potential hazards

### Search Techniques
- Systematic search patterns
- Use of search tools and equipment
- Marking systems for searched areas
- Communication protocols

### Rescue Operations
- Stabilization of structure
- Access and extrication techniques
- Medical care during rescue
- Transportation considerations
